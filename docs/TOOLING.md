# How each tool in the profile is used (and where it isn't)

| Tool / skill | Meaningful role in NEXORA | Evidence |
|---|---|---|
| **SQL** | NL→SQL engine with AST guard; analytics views for NSM, activation, retention, cost per outcome; dataset tables | `backend/app/data/`, `database/analytics_views.sql` |
| **Python** | Entire backend, AI gateway, RAG, agents, workflow engine, eval runner, financial model & backlog generators | `backend/`, `ai-engine/`, `scripts/` |
| **OpenAI GPT** | Responses API adapter (tools, strict JSON schema, prompt cache key, reasoning effort); embeddings provider | `ai/providers/openai_provider.py`, `rag/embeddings.py` |
| **Anthropic Claude** | Messages API adapter (prompt caching, effort, strict tools, structured output, refusal fallback); primary routes | `ai/providers/anthropic_provider.py`, `ai/catalog.py` |
| **n8n** | "Run n8n workflow" node + inbound HMAC webhooks + importable workflows; NEXORA owns definitions & permissions | `automation/` |
| **RAG** | Hybrid retrieval, reranking, permission filtering, citations, injection defence, chunking sweep | `docs/RAG_DESIGN.md` |
| **AI agents / orchestration** | Persisted single-agent runtime, tool registry, approvals, budgets, metrics | `backend/app/agents/` |
| **Prompt engineering** | Grounding/system prompts, untrusted-data framing, structured-output schemas, route-specific effort | `modules/chat.py`, `agents/runtime.py` |
| **PRDs, user stories, roadmaps, backlog, MVP** | PRD with acceptance criteria; 62-story scored backlog; MVP/V1/V2 roadmap | `docs/PRD.md`, `docs/product/backlog.csv` |
| **RICE / ICE / MoSCoW** | Scores per story generated by script; prioritisation narrative | `scripts/build_backlog.py`, `docs/PRIORITISATION.md` |
| **GTM, OKRs, KPIs** | ICP, channels by CAC, launch plan; OKRs; KPI catalogue | `docs/GTM_STRATEGY.md`, `docs/PRODUCT_STRATEGY.md` |
| **A/B testing** | Deterministic assignment service + 6 pre-registered experiments (no fabricated results) | `modules/experiments.py`, `docs/EXPERIMENTATION_PLAN.md` |
| **Mixpanel** | Event taxonomy, async forwarding with `$insert_id` and org groups | `core/audit.py`, `worker/misc.py` |
| **Power BI** | Read-only role + `analytics.*` views; per-dataset connection info in the UI | `deployment/sql/readonly_role.sql` |
| **MS Excel** | Formula-driven financial model with scenarios & sensitivity; XLSX exports of query results | `docs/business/NEXORA_Financial_Model.xlsx` |
| **Postman** | 21-request collection with assertions, run via Newman | `tests/postman/` |
| **Jira** | Backlog CSV in Jira import format (Summary, Epic Link, Priority, Sprint, AC) | `docs/product/backlog.csv` |
| **Confluence** | `/docs` Markdown is structured for import into a Confluence space (one page per document) | `docs/` |
| **Cloudflare** | R2 storage adapter; edge/WAF/TLS deployment reference; integration token validation | `core/storage.py`, `docs/DEPLOYMENT_GUIDE.md` |
| **GitHub** | Repository, Actions CI, Dependabot, gitleaks | `.github/` |
| **Balsamiq-style wireframes** | Lo-fi wireframes preceding the build | `docs/USER_JOURNEYS.md` |
| **Figma** | *Not used in this build.* Design tokens are defined in code (`globals.css`); screens can be imported to Figma from the running app if a design file is needed | — |
| **Lovable / AI-assisted prototyping** | *Not used.* The UI was built directly in Next.js; Lovable would suit rapid marketing-page variants for experiment E5 | — |
| **Google Analytics** | *Planned*, not implemented: GA4 on the marketing site for acquisition metrics (CSP update required) | `docs/ANALYTICS_FRAMEWORK.md` |
